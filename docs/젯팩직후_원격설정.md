# JetPack 세팅 직후 원격 환경 설정 순서 (약 1시간)

`docs/원격개발_환경.md`의 권장 구성을 실제로 만드는 순서입니다. 명령은 스크립트로 묶어 두어 따라 치기만 하면 됩니다.
진행하다 막히면 그 단계의 출력 전체를 Claude에 붙이십시오.

## 미리 끝내 둘 것 (차량 없이)

| 할 일 | 누가 | 확인 |
|---|---|---|
| 원격 환경 PR(#2)을 `main`에 합치기 | 도균 | GitHub에서 Merge. 합치지 않으면 차량의 `clone` 단계가 멈춥니다 |
| 팀 공유기 설치, SSID·비밀번호 정하기 | 도균 | 노트북이 공유기 와이파이에 붙음 |
| 팀 `ROS_DOMAIN_ID` 번호 정하기 (예: 30) | 도균 | 차량은 이 번호, 노트북은 31·32·33 |
| 노트북 3대에 git, VS Code, Foxglove(또는 Lichtblick) 설치 | 각자 | 실행됨 |
| 노트북에 저장소 받기: `git clone https://github.com/DO-GYUN-KIM/AXEL_LIMO.git` | 각자 | 팀원은 Collaborator 초대를 수락한 뒤 |

## 1. 차량을 공유기에 연결 (차량 화면 또는 NoMachine)

JetPack 직후에는 SSH가 아직 안 될 수 있으므로 이 단계만 차량 화면에서 합니다.
1. 오른쪽 위 와이파이 메뉴에서 팀 공유기 선택, 비밀번호 입력.
2. 터미널에서 `ip -br addr` → `wlan0`의 주소(예: `192.168.0.23`)를 적습니다.
3. 공유기 관리 화면(ipTIME이면 `192.168.0.1`)에서 그 주소를 **고정(DHCP 예약)** 합니다. 예: `192.168.0.50`. 차량 재부팅 후 그 주소인지 확인합니다.

## 2. 노트북 설정 (각자, PowerShell, 저장소 폴더에서)

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup\laptop_setup.ps1 -CarIp 192.168.0.50 -Name 도균
```
하는 일: 내 SSH 키 생성 → `ssh limo` 별칭 → 차량에 키 등록(wego 비밀번호 1~2번 입력) → 차량에 `car_setup.sh` 전송 → git `car` 원격 추가.
확인: `ssh limo` 가 비밀번호 없이 열립니다.
SSH 자체가 거부되면(차량에 SSH 서버 없음) 차량 화면에서 `sudo apt install -y openssh-server` 후 다시 실행합니다.

## 3. 차량 점검·설치 (노트북에서 `ssh limo` 접속 후)

```bash
bash ~/car_setup.sh check          # 읽기만 합니다. 출력 전체를 Claude에 붙이기
```
`[문제]`가 나오면 거기서 멈춥니다. 특히 "/opt/ros/humble 없음", "~/wego_ws 없음"은 WeGo 이미지나 백업 복원이 먼저라는 뜻입니다.

문제가 없으면:
```bash
bash ~/car_setup.sh install        # SSH 서버, tmux, foxglove_bridge, mcap 녹화 (sudo 비밀번호 입력)
bash ~/car_setup.sh bashrc 30      # 30 자리에 팀 번호. ~/.bashrc는 자동 백업
bash ~/car_setup.sh github         # 차량 전용 GitHub 키 출력
```
마지막 줄에 나온 `ssh-ed25519 ...` 한 줄을 GitHub 저장소 → Settings → Deploy keys → Add deploy key에 붙이고 **Allow write access**를 체크합니다(도균 님만 가능).

```bash
bash ~/car_setup.sh clone          # ~/axel_ws로 받고 첫 빌드
source ~/.bashrc
deploy --status                    # 배포 기록이 보이면 성공
```

## 4. 화면 확인

```bash
tmux new -s viz
viz                                # = foxglove_bridge 실행. Ctrl+B 다음 D로 빠져나와도 계속 돕니다
```
노트북 Foxglove → Open connection → Foxglove WebSocket → `ws://192.168.0.50:8765`.
드라이버(`ros2 launch wego teleop_launch.py`)를 다른 tmux 창에서 띄우면 카메라·라이다가 보입니다.

## 5. Claude Code (선택, 차량에 인터넷이 있을 때)

```bash
bash ~/car_setup.sh claude
cd ~/axel_ws && tmux new -s claude
claude                             # 처음 한 번 로그인
claude remote-control              # 휴대폰·노트북에서 이어서 지시할 때
```
저장소의 `CLAUDE.md`와 `.claude/settings.json`이 자동으로 적용됩니다(차량 사실, 주행 명령 금지 규칙).

## 6. 보안 마무리 (3명 모두 2단계를 끝낸 뒤)

```bash
bash ~/car_setup.sh harden         # 등록된 키 목록 확인 → yes → wego 비밀번호 변경 → 비밀번호 로그인 끔
```
바뀐 비밀번호는 NoMachine 접속에 씁니다. 팀 비밀 채널로만 공유합니다.
