# RTX 3070 PC에서 YOLO 학습하기

작성: 2026-11-04 · 대상: B(비전) 담당

RTX 3070(VRAM 8GB)은 YOLO11n 학습에 충분합니다. 흐름은 **PC에서 학습 → `best.pt`를 Jetson으로 복사 → Jetson에서 TensorRT 변환**입니다.

## 1. 한 번만 하는 설치 (Windows 기준, Ubuntu도 같음)
1. NVIDIA 드라이버를 최신으로 업데이트합니다.
2. Python 3.10 또는 3.11을 설치하고(Anaconda/Miniconda 권장) 새 환경을 만듭니다.
   ```
   conda create -n yolo python=3.10 -y
   conda activate yolo
   ```
3. GPU용 PyTorch를 먼저 설치합니다. 명령은 pytorch.org의 "Get Started"에서 CUDA 12.x용을 골라 그대로 복사합니다.
4. Ultralytics를 설치합니다.
   - **Jetson의 `dl_env`에 깔린 버전과 같은 버전**을 설치합니다. Jetson에서 `pip show ultralytics`로 확인할 수 있습니다.
   - 버전이 다르면 Jetson에서 `.pt`를 불러오다 실패할 수 있습니다(추정).
   ```
   pip install ultralytics==<Jetson과 같은 버전>
   ```
5. GPU가 잡히는지 확인합니다.
   ```
   python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
   ```
   결과가 `True NVIDIA GeForce RTX 3070`이면 됩니다.

## 2. 데이터 폴더
`yolo_labeler`로 만든 결과를 이 구조로 둡니다.
```
dataset/
  images/train/*.jpg   images/val/*.jpg
  labels/train/*.txt   labels/val/*.txt
  data.yaml
```
`data.yaml`의 클래스 순서는 라벨링할 때 입력한 순서와 **반드시** 같아야 합니다.
```yaml
path: D:/autorace/dataset        # 절대 경로
train: images/train
val: images/val
names: [red, yellow, green, pedestrian, left_A, right_B, slow, parking]   # 임시
```
val에는 전체의 10~20%를 넣습니다. 같은 장면을 연속으로 찍은 사진은 train과 val에 나눠 넣지 말고 한쪽에만 넣습니다. 나눠 넣으면 점수가 실제보다 좋게 나옵니다.

## 3. 학습
```
yolo detect train model=yolo11n.pt data=D:/autorace/dataset/data.yaml imgsz=640 epochs=150 batch=32 patience=30 workers=4 project=runs name=v1
```
- 메모리 부족 오류가 나면 `batch=16`으로 줄입니다.
- Windows에서 데이터 로더 오류가 나면 `workers=0`으로 바꿉니다.
- 1~2천 장이면 수십 분 걸린다고 봅니다(추정).
- 결과는 `runs/v1/weights/best.pt`에 생깁니다. 클래스별 mAP는 `runs/v1/results.png`와 학습 로그에서 봅니다.
- 학습할 때 색을 크게 바꾸는 증강(`hsv_h`)은 기본값보다 작게(예: `hsv_h=0.005`) 두는 것을 권합니다. 신호등은 빨강·노랑·초록 색 자체가 정답이므로, 색을 바꾸면 클래스를 헷갈리게 됩니다(추정).

정확도가 모자랄 때만 `model=yolo11s.pt`로 키웁니다. Jetson에서 추론 시간이 늘어나므로 실제 차에서 프레임 속도를 꼭 확인합니다.

## 4. Jetson으로 옮기고 변환
```
scp runs/v1/weights/best.pt wego@<로봇IP>:~/models/v1.pt
```
아래는 Jetson에서 실행합니다. 변환 결과 파일은 만든 장치에서만 동작하므로 PC에서 변환하면 안 됩니다.
```
conda activate dl_env
ros2 run dl_ros2_application yolo_to_trt ~/models/v1.pt
```
그다음 `yolo_object_detect`의 `model_weight_path`에 생성된 `.engine` 경로를 넣어 실행합니다.

## 5. 재학습 반복 (라벨링 시간 줄이기)
1. 새 사진을 찍습니다. 오검출 장면과 광고 모니터 화면을 우선합니다.
2. 직전 모델로 박스를 미리 그립니다.
   ```
   yolo detect predict model=runs/v1/weights/best.pt source=new_images save_txt=True conf=0.3
   ```
3. `yolo_labeler`에서 틀린 박스만 고칩니다.
4. 기존 데이터에 합쳐 `name=v2`로 다시 학습합니다. 처음부터 학습해도 되고, `model=runs/v1/weights/best.pt`로 이어서 학습해도 됩니다.
